# Sound path

Tile-based sound propagation for the local player (client-only, `_Maid` folders; the server is not involved). Replaces the engine's single-raycast occlusion — and, through `ProcessStreamOverride`, the engine's whole stream update — with a weighted shortest-path model: how a sound reaches the player depends on the cheapest tile path between them and on the muffling objects that path crosses. Blocker muffle is folded into one occlusion scalar that the engine lowpass carries, the distance fade rides the stream volume as plain dB, and a sound is born at its final loudness.

## Pieces

- `Content.Client/_Maid/Audio/PathSound/PathSoundSystem.cs` — the whole mechanism: field building, the stream-processing override, the occlusion model, debug state.
- `PathSoundOverlay.cs`, `PathSoundOverlayCommand.cs` (`showsoundpath`), `PathSoundOverlayModeCommand.cs` (`soundpathmode`), `PathSoundDebugCommand.cs` (`soundpathdebug`), `PathSoundSnapshotCommand.cs` (`soundpathsnap`) — debug tooling.
- `Content.Shared/_Maid/Audio/SoundPathWeightComponent.cs` — networked `muffle` percent (0–100) that turns an entity into a blocker with exact transmission.
- `Content.Shared/_Maid/CVars/CVars.cs` (`MaidCVars`) — all tuning under `maidsound.*`.
- `Resources/Prototypes/_Maid/Audio/sound-weights.partial.yml` — partial prototypes adding the component to upstream windows and the door family; the per-object transmission table.
- `Resources/Prototypes/_Maid/Entities/Objects/Devices/sound-emitter.yml` — `TestSoundEmitter`, beeps every 5 s for playtesting (hidden from the spawn menu).

## Fields

Four Dijkstra fields are rebuilt over grid tiles around the audio listener — the eye position (`TryGetListenerField`: `CurrentEye.Position` → `TryFindGridAt` → `CoordinatesToTile`), so a Station AI's field follows its remote hologram, not the core the mob sits in; an eye off any grid tears the field down (radius from `maidsound.path_radius`, clamped 4–32). The four roots are the tiles around the listener's continuous position; receiver-side bilinear interpolation between roots keeps values continuous across tile crossings (a deliberate design decision — one root would be simpler but loses interpolation).

When `maidsound.path_detour_weight` is positive, each root also gets a **detour pass** over the same tiles with cost `1 + tileOcclusion * path_detour_weight` — a route biased toward clean tiles even when longer (with the default 20, crossing an airlock is worth ~33 tiles of detour and a wall ~1600, so the detour field routes around whole airlock rows and walls whenever any detour exists). Empty tiles are excluded from the detour pass — vacuum carries no detour sound, and without this the pass would circumvent blockers around the ends of wall lines through space wherever that is cheaper than the blocker (the shortest pass is allowed its vacuum routes; tests seal against those). The primary pass keeps its own arrays; the detour pass fills the `*2` field arrays and reuses the settled flags and the tile-weight cache. `path_detour_weight 0` skips the second pass, and the primary pass alone already detours past walls whenever the detour is cheaper in `1 + occl` terms — the detour pass exists for *cheap* blockers (airlocks, windows) that the shortest path crosses even though a clean route runs nearby.

Cost of entering a tile is `1 + tileOcclusion`, from the anchored entities:

- an entity with `SoundPathWeightComponent` contributes `OcclFromMuffle` (`-ln(1 - muffle/100)`; muffle 100 maps to the 400 clamp, whose exponential underflows to exact zero) while its physics body `CanCollide` is true — open or destroyed doors drop out, welded ones stay; a door whose `DoorComponent.State` is `Closing` also counts even while its collision is still flipped off, so a closing airlock's own sound muffles from the moment the animation starts. An **opening** door deliberately follows its live collision: it blocks until the mid-animation `CanCollide` flip (`OnPartialOpen`) and passes sound from there on;
- otherwise a hard fixture on `Impassable` counts as a wall (`path_occlusion_per_weight * weight_opaque`, or `weight_glass` on `GlassLayer`); fixture layers exactly equal to `AirlockLayer`/`GlassAirlockLayer` count too — airlock fixtures carry no `Impassable` bit (`AirlockLayer = Opaque | GlassAirlockLayer`), so the vanilla occlusion raycast never sees airlocks at all. The door family is fully table-covered (`Airlock` 100, `AirlockGlass`/`BaseWindoor`/`FirelockGlass` 99, `BaseFirelock`/`BaseShutter` 100 — the latter also covers blast doors, whose own fixture layer `HighImpassable` matches no heuristic mask).

Component objects are absolute (percents, independent of cvars); heuristic objects scale with cvars. Rebuilds happen when the listener's base tile, grid or radius changes, when a blocker event fires — a directed `(DoorComponent, DoorStateChangedEvent)` subscription prices only the changed door's tile (doors outside the field window are ignored: they cannot affect this field) and skips the rebuild when the tile's cached weight is unchanged (e.g. Closing → Closed keeps the weight); `CollisionChangeEvent` covers `CanCollide` flips of **anchored** bodies only (walls, doors, windows — items and projectiles are filtered out), including the mid-closing moment when a door becomes solid (which fires no door-state event); `AnchorStateChangedEvent` and `TileChangedEvent` cover built, broken and re-anchored blockers. Non-door events are throttled to one rebuild per 100 ms. Tile-step and event rebuilds run **on the thread pool** into a scratch buffer that is copied over the live field on the next frame update; grid, radius and door-state changes rebuild **synchronously on the main thread** — door audio is client-predicted (`PlayPredicted` → the client's forced stream processing starts the source mid-tick, the same tick the state flips), so the fields must be fresh before that tick's stream runs.

Tile weights are cached **per world tile in a persistent dictionary** shared by all four roots (the per-root recomputation of identical weights was the dominant rebuild cost) and copied into a window array for the passes; vacuum tiles carry an empty sentinel that also excludes them from the detour pass. The cache is invalidated per tile by the blocker events, fully refreshed when the grid changes or the TTL elapses (the full-refresh stamp advances only on an actual full refresh, so the fallback cannot be starved by event storms), and a blocker-free window skips the detour passes entirely. `soundpathdebug` reports the last rebuild time.

## Per-sound values

`TryGetAudio` produces the per-source model, interpolated bilinearly across the receiver's tile corners (the source is read at its single floor tile — an interpolated source would dilute the blocker behind it: a grid-centered source lends its wall only a quarter of the blend, so sounds behind airlocks played nearly clean). A blocker belongs to the path a sound crosses, not to the tile it is born on: the source tile's own occlusion is always subtracted using the field's own window price — not the live world weight, which a door-state flip can leave one frame behind the field (subtracting the live weight leaked a 1-3-tick occlusion spike on the door's own sound), and not a downhill-neighbor price, which in airlock banks picked the most-blocked neighbor the route never crossed (`BankOwnSoundStaysAudible` pins this). Blending per-root gains (`e^-occl`) instead of raw occlusion turns a route disagreement into a fade instead of a silence/clean toggle. Unreachable field tiles (sealed rooms) are skipped in the blend instead of contributing a fake-clean zero. A root seeded on a blocker tile — a listener corner hugging a wall or a closed airlock — is skipped too (unless the sound itself is born on that tile): its routes start past the blocker and would cross it for free, diluting the blend of the honest roots.

Per root, the detour field's value is blended in only when the **direct route is dead** (`occlR1 >= AudibleDirectCeiling` 6.9 = 0.1% transmission — the per-object transmission table governs audible crossings; detours rescue only dead ones), its fully folded value is strictly better than the primary's, **and** the detour takes enough extra hops past the direct route — clean corridors (both paths equally clean), sealed rooms (no detour reachable) and short bypasses through neighboring open doors of an airlock bank keep their exact primary values, so an audible closed blocker is never defeated by a side step. A **door's own sound** takes the best dead-route detour outright (one extra hop, full share) — the engine plays entity sounds on a separate `Audio` entity **parented to the source**, so the source is found via `xform.ParentUid`, never the audio entity's own components. A detour crossing no closed-door tile ("pure", open-door tiles carry a residual `OpenDoorTileWeight` 0.005 that keeps them detectable but weight-free) relaxes the hop gate to one and blends at 70%. **`maidsound.path_purity_decay`** switches what "pure" means: by default purity counts raw closed-tile weight; in the decayed mode it is measured on the surviving occlusion (`occlR2`), so closed blockers crossed long before the source — past-decay eats them over the remaining walk — no longer gate the blend. The blend mixes the share of the detour's `e^-occl` gain into the primary's and scales the path metadata (hops, past) by the same shares; the flag lands in `DebugEntry.Detoured` for the overlay and dump.

## The stream-processing override

The system subscribes `AudioSystem.ProcessStreamOverride`, which replaces the engine's whole `ProcessStream` body for every stream. The handler replicates the engine branches — first-frame start, global-sound handling, other-map muting, `Volume = Params.Volume` (the per-tick reset always restores vanilla before the handler writes the fade on top), the max-distance clip (`sqrt(d² + z²) > MaxDistance`, z from the cached `audio.z_offset`), position and velocity — and replaces only the occlusion step:

The write is split so each part rides the engine mechanism built for it:

- `component.Occlusion = occl` — blockers only (walls, closed airlocks), at their raw path scale. The engine maps this to an EFX lowpass whose high-frequency gain is `e^-occl` and broadband gain is `e^-occl/10` (0.8686 dB per unit, `BaseAudioSource.Occlusion`), so the transmission table translates multiplicatively along the route: walls and solid airlocks muffle 100% (exact zero), glass airlocks and windows 99% (1% of the highs, −4 dB broadband), two glass doors in a row 0.01%.
- `component.Volume = component.Params.Volume − straight_distance·path_loss_db_per_tile` — the distance fade rides the stream volume as plain broadband dB, leaving the timbre intact. The route-comparison folds `f1`/`f2` inside `TryGetAudio` stay route-length-based: they decide *which* path wins, not how loud it plays.

Folding distance into the occlusion instead would drive the lowpass HF gain to `e^-occl` and wipe mid-frequency content long before the broadband fade matters (beeps died while low door thuds survived and hid the effect) — hence the split. Both written values are smoothed per stream; the volume write is absolute from `Params.Volume` (the engine resets `Volume = Params` every tick; `Params` itself is never touched), so there is no compounding. `occl` is the blended path muffling with the past-tile decay behind the last blocker already applied. The blocker occlusion is clamped to 400. Doppler velocity is replicated exactly like the engine does (`component.Velocity = GetMapLinearVelocity(parentUid)`).

This placement is load-bearing: client-predicted sounds (`PlayPredicted` — doors, footsteps, melee; ~300 call sites) start their source mid-tick inside `PlayPredicted`, and the forced stream processing commits their birth volume before any content code after the call can run. With the override, that same forced call computes the full model from the fresh fields — a far door's close sound is silent from its first sample. Nothing content-side can run before that point otherwise.

Beyond the field radius the handler clamps the source tile to the field edge (per-axis clamp, not a ray walk) and uses its accumulated occlusion; the straight-line distance fade covers the remainder — there is no edge remainder raycast. A source on another grid skips the field entirely (foreign coordinates would map onto an arbitrary field tile) and takes the plain raycast (`IntersectRayPenetration`, mask widened by `GlassAirlockLayer` since airlock fixtures carry no `Impassable` bit, ignoring the source entity like the engine does). Raycast penetration is vanilla meters and is converted to field units (`Round(pen / tileSize)` walls × the wall heuristic) so the fallback speaks the same scale as the field; grazing rays under half a tile stay free.

Per-stream smoothing: the computed value is lerped in a `ConcurrentDictionary` (the handler runs on parallel audio-job threads when ≥ 5 streams exist; races are benign — a lost update just converges one tick later), so rebuild steps fade over a few ticks instead of snapping the filter. Stale entries are swept from the frame update.

## Invariants and failure modes

- Background builds run in two preallocated scratch buffers: `PostBuild` returns false when both are busy and the trigger's `_dirty` flag is cleared only on a successfully posted build; a build dropped by a synchronous rebuild (a door event during flight) is released by its own worker once it stops writing the arrays. An earlier version left dropped buffers busy forever, which froze the field on its old base tile and burned ~2800 cache lookups per frame.
- A directed `(component, event)` subscription pair allows exactly one handler per client (`EntityEventBus` throws on duplicates), and a failed connection attempt re-runs system `Initialize` on the next join. This system owns exactly one directed pair — `(DoorComponent, DoorStateChangedEvent)`, whose handler in this RT binds to `EntityEventRefHandler` (a `ref` signature is required) — everything else is broadcast, and the smoothed-entry dictionary is swept lazily instead of via `ComponentShutdown`.
- Broadcast subscriptions to one event must all agree on by-ref or by-value (`EntityEventBus` throws on a mix during join-time re-initialization, which fails the join). Engine struct events this system listens to — `TileChangedEvent`, `AnchorStateChangedEvent`, `CollisionChangeEvent` — are by-ref and keep `ref` handlers; class events like `DoorStateChangedEvent` are by-value.
- The handler never mutates main-thread-only state: field reads are pure (a read racing the main-thread rebuild can only miss a tile for one tick — benign fallback to the raycast), the smoothed dictionary is concurrent, and `AudioComponent` volume/gain/position/occlusion writes are what the engine itself does from the same job threads.
- `ProcessStreamOverride` supports a single invocation target — this system must remain the only subscriber.
- Sounds the engine never occludes are out of scope: `AudioFlags.NoOcclusion` (grid audio such as the FTL rumble) gets `Occlusion = 0`, global sounds skip occlusion entirely, and out-of-range sounds are gain-clipped by the replicated max-distance branch.
- The model only shapes what reaches the engine lowpass — the vanilla loudness chain sits on top and the overlay does not show it: a source's base volume (`Params.Volume`, often −6…−20 dB), OpenAL's linear distance rolloff and each sound's own `MaxDistance` (`AudioParams.Default` = `SharedAudioSystem.DefaultSoundRange` = **15 m**) can all silence a sound the field marks clean. Beyond `MaxDistance` the handler hard-mutes the stream before consulting the model, recording a `DebugEntry` with `Mode = MaxDistanceClip` (red `MD d:>…` markers). Per-sound estimates of the full chain (`engineGainEst`, `estLoudnessDb`) and every parameter involved are in the `soundpathsnap` dump.
- The outermost hard ceiling on hearing distance is **server PVS**, above both `MaxDistance` and the model: entity sounds only reach a client while the emitting entity is inside PVS (`net.pvs_range` = 25 → a 25×25 square ≈ **12.5 tiles** from the eye; chunk boundaries give a little grace). Past that there is no `AudioComponent` on the client at all — no stream, nothing for the model to process, no marker. A "sound silent at N tiles" report must first check the source distance against this bound. Deliberately left at default: PVS gates everything (visibility, networking, spawn), not just audio, so it is not raised for sound testing — long-range hearing tests stay within ~12–13 tiles of the source.
- An open corridor end into space lets the primary pass route clean through vacuum past any 0%-transmission wall or door (vacuum hops cost 1 in the primary). Rooms fully enclosed by walls are safe — every escape crosses a 0% blocker. If in-game leaks are reported through open corridor ends, exclude vacuum tiles from the primary pass like the detour pass already does.

## Debug

`showsoundpath` toggles the overlay; `soundpathmode <off|field|numbers|all>` picks what is drawn: tiles colored by audibility (green ≥ 0.7 clean, yellow muffled, red barely, grey no path), per-tile percentages, sound markers colored by `e^-filter` with their `o:` (path occl), `f:` (folded filter) and `v:` (source base volume dB) values — a red `MD d:…>…` marker instead means the engine hard-muted the stream past the sound's own `MaxDistance` before the model was consulted — and a legend with all tuning values plus the caveat that tiles, percentages and markers show the model only, with source volume, rolloff and `MaxDistance` applied on top. In field/all modes each sound also draws **how it reaches the player**: the reconstructed route as translucent tile strips plus a polyline from the source to the listener — orange for the shortest route, cyan for the detour when it participates (`TryGetRoute` walks the fields downhill from the sound's tile to the dominant root, no stored parents needed). Tile colors still reflect the primary route only; the routes and markers carry the blended truth. `soundpathdebug` dumps the last filter values per sound (`*detour` marks blended ones, `*MD` clipped ones). `maidsound.path_smoothing` sets the fraction of the gap to the raw filter value closed per call; `maidsound.path_detour_weight` scales blocker cost on the detour pass (0 = detours off); `maidsound.path_purity_decay` switches detour purity to the past-decayed measurement; `maidsound.path_enabled false` unsubscribes the override and reverts to engine behavior entirely.

`soundpathsnap [label]` writes a full JSON snapshot of the state into the client user data dir (`soundpath/snap-<timestamp>-<label>.json`; the command prints the absolute path) for offline analysis: effective cvars (including `audio.z_offset`, raycast length, occlusion mask and master gain), listener position, field state, the whole tile-weight cache, all four root fields (reachable tiles only, detour values null when unreachable), every live `AudioComponent` with its engine parameters (`FileName`, base/applied volume, gain, `MaxDistance`, rolloff, ref distance, clip verdict, a mirrored `LinearDistanceClamped` gain estimate and a full-chain `estLoudnessDb`), the model verdict per stream, per-root breakdowns (occl/hops/past per pass, detour share decision with both folded `f1`/`f2` values), reconstructed routes and a ring of the last 1024 per-stream model decisions (`occl`/`sumW`/`len`/`past` included) for catching birth-time transients; dead streams linger ~10 s in the dump.

The shipped cvar defaults are the play-tested preset: `weight_opaque 8`, `path_occlusion_per_weight 15` (a wall tile costs 120 occl units → absolute silence), `path_occlusion_loss_db 15` (weights occlusion in the route-selection folds only — closed blockers look expensive so clean detours win; the filter itself carries the raw muffle percent), `path_loss_db_per_tile 1.5` (≈ 40-tile hearing radius), `path_radius 25`, `path_detour_weight 20`, `path_purity_decay false`. The transmission table in `sound-weights.partial.yml`: windows and `AirlockGlass`/`BaseWindoor`/`FirelockGlass` 99 (1%), `Airlock`/`BaseFirelock`/`BaseShutter` 100 (exact zero); unmarked hard fixtures fall back to the wall/glass heuristics — a bare `Grille` scores 4.5 (window-class), `GrilleDiagonal` 120 (wall-class). All `maidsound.*` cvars are `ARCHIVE` — a value once set in the client console persists across restarts and overrides newer code defaults until it is set again or removed from `client_config.toml`.

## Prior art

The same problem space, for comparison: Barotrauma vanilla compares the source's and listener's hulls (plus a water path) and applies a lowpass — coarse, per-hull rather than per-tile; the community [Soundproof Walls mod](https://github.com/Plag0/Soundproof-Walls) ramps a cutoff per obstruction between hulls. Thief and The Dark Mod (Doom 3) build a **portal graph where doors are dynamic portals** — opening one changes the propagation graph, exactly what this system's door-event rebuilds do. CS:GO's 2017 audio overhaul occludes "through and around materials" with traces — the path model adds the around-routing on top of a trace. Academic work (portal propagation caches, [Project Triton](https://arxiv.org/abs/2107.11548)) treats doors-as-dynamic-portals as the hard part and solves it the same way we do: recompute the propagation data on geometry change. Where this system differs: the loudness split (blockers in the lowpass, distance in the volume) plus the transmission table make per-object audibility an explicit, tunable contract.

## Testing

The model is deterministic and covered by integration tests (`Content.IntegrationTests/Tests/_Maid/PathSoundTest.cs`; run with `dotnet test Content.IntegrationTests/Content.IntegrationTests.csproj -c Tools --filter "FullyQualifiedName~PathSound"`, 14 tests). Each test builds a sealed scene, places blockers, and asserts the folded filter against the analytic expectation — blockers minus the past-decay, plus the straight-line distance fade. The contract matrix (defaults): a clean 10-tile corridor ≈ 17 occl units (pure fade); one closed solid airlock, a vestibule, or five airlocks in a row = silence band (filter > 30 — every route transmits nothing); a glass airlock or window (1%) crosses at occl 4.6, ≈ 20 with the source five tiles past; a wall in a sealed room ≈ 137 (raw wall occl 120 + straight fade); a source born on an airlock tile is exempt from its own tile; a glass airlock with a clean detour nearby is NOT bypassed — the filter equals the primary value with detours on and off; sources past the field edge fold the straight remainder. Rough hand bands: occl < 1 clean, 4.6 = 1% highs (−4 dB bass), > 10 highs dead with bass following at −0.87 dB per unit. The full test contract matrix, scene recipes and integration-test gotchas live in `.claude/docs/systems/sound-path-tests.md`.
