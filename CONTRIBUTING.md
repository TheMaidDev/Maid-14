# Контрибьютинг

## Структура

Содержимое `_Maid/` - контент нашего билда.
В нём должны находиться все наработки конкретно текущего билда.
Полностью свободен для редактирования.

## Код

Можно делать небольшие правки кода вне `_Maid` папок с пометкой `// MAID {change}`.
При переопределении логики старый код необходимо закомментировать.

Более крупные правки надо выносить в `_Maid`.
Для этого можно:
* Создать новый ивент внутри `_Maid` и вызывать его вне `_Maid`
* Продублировать систему и компоненты

## Прототипы

Оригинальные прототипы (вне `_Maid`) трогать **запрещено**.
Модифицировать их можно через partial-прототипы.

Partial-прототипы можно объявить внутри `*.partial.yml` файлов.
Для переопределений нужно использовать `!PartialOnly` тег (его можно опустить только в редких случаях).

[Гайд на partial-прототипы](./PARTIALS.md)

## Ресурсы (текстуры, звуки)

Путь нового ресурса должен повторять оригинальный, с `_Maid` после корневой папки типа ресурса:

```
Resources/Textures/Some/Path/To/File.rsi        # оригинал
Resources/Textures/_Maid/Some/Path/To/File.rsi  # переопределение
```

*Массовые* переопределения звуков и текстур (без логики!) должны располагаться в папке `Override`,
в ней все прототипы по умолчанию являются partial.

## Переводы

Переводы можно менять без меток.
